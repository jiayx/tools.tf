# PRD - TaskFlow AI MVP

## 1. 产品定位

将 syllabus、群消息、备忘录中的自然语言任务信息，自动转化为可执行任务，并通过日历导出形成闭环提醒。

目标用户：学生、兼职/全职忙碌人群。

## 2. MVP 目标

1. 输入一段文本，自动解析任务候选。
2. 自动补齐 due 时间并标注歧义。
3. 自动评估复杂度与耗时，给出 3-5 步执行清单。
4. 计算并展示 start-by（最晚开始时间）。
5. 提供预览纠错页，让用户快速批量确认。
6. 导出 `.ics`（每任务两事件：Start-by + Due）。

## 3. MVP 边界

不做：

1. 原生推送和系统通知。
2. 步骤级提醒触发。
3. 任务反推催办与惩罚机制。
4. 表格导入。

## 4. 页面信息架构

1. 导入页：粘贴文本并设置解析参数。
2. 解析预览页：逐项修正并批量创建。
3. 任务库：分组执行视图（即将开始/即将到期/进行中/已完成）。
4. 任务详情页：字段总览、步骤勾选、ICS 下载。

## 5. 时间语义

内部存储：

- `due_at_utc`
- `due_tz`
- `start_by_utc`
- `start_by_tz`

展示：

- 前端默认展示为任务原始时区（UI 可扩展为切换本地时区）

## 6. 默认补齐规则

1. 仅日期 -> `23:59`
2. “周五前/今晚前/before” -> `18:00`
3. “上午/早上” -> `09:00`
4. “晚上/今晚” -> `20:00`

所有自动补齐都在预览页显示 flag。

## 7. Start-by 算法

1. `days_by_hours = ceil(estimated_hours / 2)`
2. `min_lead_days_by_complexity`: 低 1 / 中 3 / 高 5
3. `lead_days = max(days_by_hours, min_lead_days_by_complexity)`
4. `start_by = due - lead_days`

## 8. 可视化纠错策略

1. `DATE_AMBIGUOUS`：日期歧义（如 2/3）
2. `MISSING_TIME_DEFAULTED`：缺失时间已补齐
3. `FUZZY_TIME_DEFAULTED`：模糊表达已补齐
4. `MISSING_DUE`：缺失截止时间
5. `LOW_CONFIDENCE`：低置信度候选

## 9. 验收标准

1. 一段混合文本能解析出候选任务。
2. 预览页可编辑任务核心字段和步骤（3-5 条约束生效）。
3. 每个有 due 的任务都有 start-by（可锁定覆盖）。
4. 任务库支持分组、搜索、快速编辑。
5. 导出 `.ics` 包含每任务两个事件，导入日历后时间正确。
